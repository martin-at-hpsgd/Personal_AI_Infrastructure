# Science Examples

A supported hypothesis need not achieve the goal: reducing abandonment from 40% to 36% can support an intervention while missing a below-25% target.

Likewise, an overall prompt score above its target cannot override failed length, key-point, or format criteria. Judge each precommitted criterion separately; a combined variant's win does not establish which component caused it.

Apply these distinctions in [StructuredInvestigation](Intents/StructuredInvestigation.md)'s Analysis and Iteration rows. HillClimb applies them to measured climbs (`skills/HillClimb/References/Experiments.md`).
