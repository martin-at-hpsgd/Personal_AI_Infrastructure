Problem types, and how each one shapes the visual metaphor:

| Problem Type | Description | Visual Metaphor |
|--------------|-------------|-----------------|
| **SORTING/CLASSIFICATION** | Need to categorize things into the right buckets | Scattered items + empty labeled bins |
| **COMMUNICATION** | Can't express ideas clearly, talking past each other | Tangled speech, broken telephone |
| **DOUBLE STANDARD** | Same thing judged differently based on source | Tilted scales, unfair judges |
| **MISDIRECTION** | Focusing on wrong thing, missing the real issue | Looking left while danger is right |
| **OVERWHELM** | Too much to process, can't see clearly | Flood of items, buried figure |
| **MISSING FRAMEWORK** | No structure to organize thinking | Chaos vs. empty scaffolding |
| **FALSE DICHOTOMY** | Forced choice that ignores better options | Two doors, hidden third path |
| **COMPLEXITY** | Simple thing made unnecessarily complicated | Tangled vs. straight path |
| **BLINDSPOT** | Can't see obvious thing right in front | Figure ignoring elephant |

**Examples with problem types:**
- A threat-classification framework → Problem TYPE: SORTING — "When you have a threat, which category does it belong to?"
- AI judgment essay → Problem TYPE: DOUBLE STANDARD — "Same output judged differently based on source"
- Security theater → Problem TYPE: MISDIRECTION — "Focus on visible but ineffective measures"
- Meaning essay → Problem TYPE: MISDIRECTION — "Chasing status instead of purpose"

Concrete subjects come straight from the content: "Bowling pins" → draw bowling pins; "Hands juggling" → draw hands juggling; "Balance between capital and labor" → draw a balance/scale metaphor.

Figures showing the problem: judges applying double standards, people ignoring obvious issues, actors making the mistake the essay critiques. Emotional treatment follows the problem: unfairness shows the tipped scale, confusion the wrong focus, loss what is fading.

**Worked example — Capitalism vs Communism essay:**

| Side | Concept's failure mode | Iconic imagery (pick 2-3) | Color wash |
|------|------------------------|---------------------------|------------|
| LEFT (communism failure) | Compassion-feeling → centralized super-class crushing the spirit, uniformity, all-powerful state | Monolithic brutalist statue/watchtower with a single dominating figure or eye; a lockstep column of faceless figures below it; brutalist concrete blocks; surveillance/watchtower silhouette | Deep indigo #2B4C7E wash |
| RIGHT (capitalism failure) | Cruelty-feeling → malignant inequality when unchecked, chaos, exploitation | Gilded skyscraper / glittering spire with a tiny beggar/destitute figure at its base; smokestacks belching smoke; oligarch silhouette on a gilded throne; sharp wealth contrast between palace and slum | Burnt umber #A0522D wash |

**Emotional registers** (examples; the CSE-24 can surface any register):

| Content About... | Register | Warm:Cool | Visual Treatment |
|------------------|----------|-----------|------------------|
| AI danger, existential risk, loss of control | DREAD / FEAR | 20:80 | Heavy, dense, oppressive linework |
| Human potential, growth, positive futures | HOPE / POSSIBILITY | 80:20 | Light, ascending, open |
| Philosophy, meaning, deep questions | CONTEMPLATION | 50:50 | Balanced, still, thoughtful |
| Security threats, calls to action | URGENCY / WARNING | 60:40 | Fractured, dynamic, tense |
| Breakthroughs, encountering the vast | WONDER / DISCOVERY | 40:60 | Revelatory, light breaking through |
| Overcoming obstacles, "gym" work | DETERMINATION / EFFORT | 70:30 | Strong, grounded, effort-showing |
| Endings, what's lost to progress | MELANCHOLY / LOSS | 40:60 | Fading, dissolving, trailing off |
| Human bonds, community | CONNECTION / KINDNESS | 90:10 | Warm, intimate, multiple figures |
