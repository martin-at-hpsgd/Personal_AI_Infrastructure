# RapidCycle

A small but genuinely evolved portfolio from a time-boxed novelty cycle, presented as cycle 1, not as proof.

## Ideal State

- In a time-boxed setting, the result is a small but genuinely evolved portfolio rather than a familiar list, and it names the one reality check that should govern a longer run.
- The compressed population passed through every rapid-cycle phase, CONSUME through TEST and then SELECT (SKILL.md § Phase vocabulary), and the lineages show it.
- The portfolio draws on at least two unrelated disciplinary lenses, one deliberately imperfect mechanism transfer, and multiple parent lineages.
- The output labels itself cycle 1 and makes no claim that it is proof.

## Anti-criteria

- Never compresses away DREAM, deliberate misapplication, reality testing, or diversity selection.
- If the time budget cannot support these, never claim an evolutionary run; recommend BeCreative for a single-pass brainstorm instead.
- BeCreative is never used outside CONSUME, DREAM, DAYDREAM, or SALON, never for anything but fast divergent expansion, and never in place of Novelty’s lineage, testing, and selection contract.

## Output format

Return:

- **Reality frame:** problem, hard constraints, and the one decisive test.
- **Three or more candidates:** different niches, each with lineage, mutation/transfer, fantasy-or-evidence label, and test status.
- **Selected portfolio:** a leading candidate, a contrarian wildcard, and an explanation of the diversity retained.
- **Next evolution rule:** what to amplify, suppress, or test in cycle 2.
