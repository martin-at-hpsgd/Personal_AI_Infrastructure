# Voice Calibration — ExtractWisdom bullets

How an ExtractWisdom bullet should sound. The three-level ladder is a teaching device, not a template. When the install has `LIFEOS/USER/PRINCIPAL/WRITINGSTYLE.md`, it is the canonical voice reference.

Every bullet lands at **Level 3**: how you'd actually say it out loud to a friend. It reads naturally when spoken, varies sentence length, uses periods rather than em-dashes, and is opinionated but understated, letting the content carry the weight. The reader should think "I want to watch this," not "I got the summary."

## The three levels

**Level 1 (bad: documentation voice):** flat, passive, "The speaker discussed…", "It was noted that…".

- The speaker discussed the importance of self-modifying software in the context of agentic AI development
- It was noted that financial success has diminishing returns beyond a certain threshold
- The distinction between "vibe coding" and "agentic engineering" was emphasized as meaningful

**Level 2 (better, but still "smart bullet points": compressed info with em-dashes):**

- He built self-modifying software basically by accident — just made the agent aware of its own source code
- Money has diminishing returns. A cheeseburger is a cheeseburger no matter how rich you are.
- "Vibe coding is a slur" — he calls it agentic engineering, and only does vibe coding after 3am

**Level 3 (yes: conversational, the principal's voice):**

- He wasn't trying to build self-modifying software. He just let the agent see its own source code and it started fixing itself.
- Past a certain point, money stops mattering. A cheeseburger is a cheeseburger no matter how rich you are.
- He calls vibe coding a slur. What he does is agentic engineering. Vibe coding only happens after 3am, and he regrets it by morning.

Level 2 compresses the information; Level 3 lets a thought breathe across short sentences, clear and direct and a little bit personal.

## Samples never appear in output

Every literal example string above is a calibration sample only. They describe a different source (self-modifying software, the cheeseburger line, vibe-coding-after-3am), so if any of them shows up in an extraction — "a cheeseburger is a cheeseburger no matter how rich you are," the self-modifying-software lines, the vibe-coding/agentic-engineering lines — the extraction copied this reference instead of extracting the content in front of it.
