# Voice and Style Guide for Story Explanations

Story-explanation-specific guidance. The voice file and voice notes named in `LIFEOS/USER/CUSTOMIZATIONS/SKILLS/StoryExplanation/Config.md` define the voice; the defaults below apply wherever they are silent. AI pattern detection: `LIFEOS/DOCUMENTATION/Writing/AIWritingPatterns.md`.

---

## The User's Voice

### Default characteristics
- **First person perspective** ("In this post, I argue...", "I find this interesting...")
- **Plain and direct**
- **Natural conversational tone** (like telling a friend)
- **Never flowery, emotional, or journalistic**
- **Let the content speak for itself**

### Good Examples
```
"In this talk, a city planner explains why most bus routes lose riders at the transfers."
"I think her main point is that a short wait matters more than a fast ride."
"Her fix cost almost nothing, and I like that more than anything else in the talk."
```

### Voice Signals (What to Do)
- Opening hooks the reader with plain, direct language
- Body flows naturally with varied sentence length
- Story escalates logically (background -> points -> implications)
- Closing delivers "wow" factor without hyperbole
- Reads naturally when spoken aloud
- Sticks to facts from the content
- Feels like the user sharing something interesting with a friend

## Cliche Phrases to Avoid

A default list. The voice notes in Config.md can add phrases or replace the list; with no notes, never use these in story explanations:

| Avoid | Why |
|-------|-----|
| "at a crossroads" | Cliche, dramatic |
| "game-changer" / "game changing" | Overused buzzword |
| "double-edged sword" | Cliche metaphor |
| "paradigm shift" | Corporate speak |
| "revolutionary" | Hyperbolic |
| "groundbreaking" | Journalistic cliche |
| "alarming" | Sensationalist |
| "shocking" | Sensationalist |
| "incredible" | Vague, overused |
| "mind-blowing" | Hyperbolic |

## Sentence Style

### Length Variation
- **Target**: 8-16 words per sentence
- **Mix**: Some short (8-10), some medium (11-14), some longer (15-16)
- **Never**: All sentences the same length

### Flow Pattern
```
background -> main points -> examples -> implications -> wow factor
```

### Bad Signals (What to Avoid)
- Journalistic or academic tone
- Formulaic structure
- Extrapolating beyond the input
- Flowery or emotional language
- Cliche phrases
- Bullet points or numbered lists in final output (unless format requires it)

---

## Reading Level

Write at **9th-grade English level**:
- Conversational, not dumbed down
- Complex ideas explained simply
- Natural vocabulary a smart friend would use
- No jargon unless necessary and explained
