# ArtDirection — Preferences

`skills/ArtDirection/Tools/Critique.ts` appends everything below the next rule line to `References/Rubric.md` in every judge prompt, so the judges read these as rubric rules. The critique's `check_set.version` hashes the skill rubric and this file together, so editing either changes the version. Delete the example rules below, or the whole file, to judge by the skill rubric alone.

---

**Concept calibration (Alex Example, 2026-01-10).** In 20 scored posters, every top score carried one strong metaphor for its subject; weigh concept above polish.

**Human figures are stylized silhouettes (Alex Example, 2026-01-12).** When people appear, render them as gestural silhouettes in one shared color family. A photoreal face is a **major** defect.
