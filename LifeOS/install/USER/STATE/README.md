# STATE — the short-form current-state journal

Where your one-line state check-ins land ("M4", "S2 slept badly", "W" after a
workout). Written by `LIFEOS/TOOLS/State.ts`, read by the statusline, Pulse
(health board and affirmation streak), the interview skill, and Hermes.

| File | What it is |
|------|------------|
| `log.jsonl` | Append-only journal, one JSON object per line. Ships EMPTY on purpose: a fake entry would be a fake streak. |
| `current.json` | Derived snapshot (latest value + timestamp per dimension). Regenerated by `State.ts` on every log; do not hand-edit. |

## Entry shape (`log.jsonl`)

```json
{"ts":"2026-01-01T08:00:00.000Z","dim":"M","value":4,"note":"optional free text","source":"manual"}
```

- `dim` is a roster letter: `H` overall, `M` mood, `E` energy, `S` sleep, `R`
  relationships, `F` financial, `C` creativity, `CF` creative freedom; `W`
  workout, `K` walk, `A` affirmation are freshness counters and log with
  `"value": null`.
- `value` is 1 (really bad) to 5 (preferred range); higher is always better.
- `source` is `manual`, `interview`, `signal`, or `import`.

Log through the tool, never by editing the file:

```bash
bun ~/.claude/LIFEOS/TOOLS/State.ts log "M4"
bun ~/.claude/LIFEOS/TOOLS/State.ts current
```
