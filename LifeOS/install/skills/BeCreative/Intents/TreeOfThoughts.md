# TreeOfThoughts

One solution to a complex creative challenge, synthesized from the strongest elements of 3-5 fundamentally different branches.

## Ideal State

- The response is one solution synthesized from the strongest elements of 3-5 branches, each weighed on creativity and viability before the synthesis.
- The branches are fundamentally different strategies, not variants of one.
- The final solution names which branch(es) it draws from and why.
- The synthesis states what makes it novel and shows it is practical against each of the challenge's stated constraints, so both claims can be checked.
- The synthesized solution is one the principal would not have written on the first pass and still fully answers the brief.

## Anti-criteria

- No branch is a variant of another presented as a different strategy.
