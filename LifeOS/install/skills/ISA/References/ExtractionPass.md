# Extraction Pass

How Scaffold runs the Extraction Pass. Read it before the sweep whenever `Intents/Scaffold.md` § Extraction Pass says the pass runs: the full pass on new-product / new-surface substantial work, and the exemplar sweep on any ask that names a product or URL. Full artifact spec: `ISAFormat.md` § Extraction.

## Why it exists

The prompt is a pointer into the principal's intent, not the payload. Residue derivation alone made the prompt the ceiling: a one-sentence app prompt produced a 14-ISC ISA while the named reference product carried 60+ implicit requirements (the reference-product failure, 2026-08-17).

## Running the pass

- **Source classes** (one sweep, most yield rows together): *literal* (explicit wants and not-wants); *implication* (real entailment only: "local-first" entails an offline probe but not "no accounts", which is a hypothesis row, marked as such); *exemplar* (a named product is a spec by reference only after its role is recorded, comparator contract `replicate | adapt | visual-only | workflow-only | avoid`, an unclear role costing one batched ratification question; enumerate the exemplar's user-facing surface relevant to the stated comparison, each row records enumeration provenance `fetched` / `walked` / `model-prior`, never grounding it does not have); *principal corpus* (prior same-category ISAs' Decisions/Learning and any GEAR/OPERATIONAL_PREFERENCES/TELOS doctrine binding this work class beyond what is already @-imported, giving "obviously yes" rows and "obviously no" anti-criteria); *category priors* (the class rubric of a world-class instance: accessibility, error/empty/loading states, interruption handling, performance, onboarding).
- **Total disposition:** every candidate row gets exactly one disposition — `ISC-n`, `fog`, `oos` (rationale names the vision boundary), or `killed` (rationale says why). Density is measured in total dispositions, never ISC count: honest extraction of not-yet-buildable surface is fog-dominant, the one-binary-probe rule never softens, and real product work yields hundreds of dispositions.
- **Deliberate scope:** the milestone being climbed now is proposed here (`milestone:` + `milestone_progress:` frontmatter, `ISAFormat.md` § milestone close) and ratified with the dispositions; the ISA holds the full ideal state and the run closes a slice.
