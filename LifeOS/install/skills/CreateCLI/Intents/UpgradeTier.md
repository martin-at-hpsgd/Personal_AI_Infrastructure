# UpgradeTier

**Contents:** Ideal State · Anti-criteria · Tool contract · Output format

A Tier 1 (manual parsing) CLI migrated to Tier 2 (Commander.js) when it has outgrown Tier 1, with every command and the help quality intact.

## Ideal State

- The upgrade was warranted: the CLI now meets at least one of the Tier 2 indicators listed in SKILL.md. Tier 1 is production-ready indefinitely, so without an indicator the CLI stays where it is.
- Commander.js is installed in the CLI directory with `bun add commander`, and every Tier 1 command is converted to a Commander command carrying its arguments, options, description and action.
- The Commander help carries the examples and the output contract, added through `addHelpText`.
- After the migration, strict `tsc` is clean (`bunx tsc --noEmit` exits 0 in the CLI directory), `./cli.ts --help` prints every command, every command runs, all tests pass, and every command keeps exit code 0 on success and 1 on error.
- The version is bumped to 2.0.0 (a major bump), the README carries a Breaking Changes (v2.0.0) section that names what changed for callers (such as the help layout) and states what stayed the same, and users are notified if the CLI is published.

## Anti-criteria

- No premature upgrade: a Tier 1 CLI with many simple, ungrouped commands is fine, and most CLIs never need this upgrade.
- Never lets the auto-generated help be worse than the manual help it replaces.

## Tool contract

Install Commander.js in the CLI directory:

```bash
cd ~/.claude/LIFEOS/TOOLS/[cli-name]/
bun add commander
```

After converting, run the help and every command:

```bash
./cli.ts --help
./cli.ts fetch test
./cli.ts [each-command]
bun ~/.claude/skills/CreateCLI/Tools/CheckCli.ts . --json-args "<a command that prints JSON>"   # exit 0 = every check passed
```

## Output format

The migrated CLI takes these shapes: the Commander program header, converted commands, help with examples, and the README breaking-changes note.

```typescript
#!/usr/bin/env bun

import { Command } from 'commander';

const program = new Command();

program
  .name('[cli-name]')
  .description('[description from old CLI]')
  .version('2.0.0'); // Bump major version
```

**Before (Tier 1):**
```typescript
async function fetchData(arg: string, limit: number): Promise<void> {
  // ...
}

switch (command) {
  case 'fetch':
    await fetchData(args[1], limit);
    break;
}
```

**After (Tier 2):**
```typescript
program
  .command('fetch <arg>')
  .option('-l, --limit <number>', 'limit results', '20')
  .description('Fetch data')
  .action(async (arg: string, options) => {
    const limit = parseInt(options.limit, 10);
    await fetchData(arg, limit);
  });
```

Help with examples and the output contract, added through `addHelpText`:

```typescript
program
  .command('fetch <query>')
  .description('Search and fetch data')
  .option('-l, --limit <n>', 'max results', '20')
  .addHelpText('after', `
Examples:
  $ ${program.name()} fetch "keyword" --limit 50
  $ ${program.name()} fetch "api query"

Output: JSON to stdout
`);
```

# Breaking Changes (v2.0.0)

- [any change in option parsing or error messages]
