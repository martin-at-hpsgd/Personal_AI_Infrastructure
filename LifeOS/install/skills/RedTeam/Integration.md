# Red Team Integration Guide

**Use BEFORE RedTeam:**
- `Research` - Gather context, find precedents

**Use DURING RedTeam:**
- `FirstPrinciples/Deconstruct` - Decomposition methodology: break arguments into fundamental parts
- `FirstPrinciples/Challenge` - Classify constraints as hard/soft/assumption
- `LIFEOS/TOOLS/Inference.ts` cross-vendor persona calls (an `Agent` spawn only for a persona that needs live evidence) - Parallel assault

**Use AFTER RedTeam:**
- `ExtractWisdom` - Highest-signal critiques

The most devastating critiques come from challenging hidden assumptions. Invocation: "Use FirstPrinciples/Challenge on the stated constraints before parallel analysis"
