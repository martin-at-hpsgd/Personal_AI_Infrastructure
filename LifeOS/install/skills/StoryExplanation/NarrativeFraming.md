# Narrative Framing

**How to pick the angle a story explanation is told from.**

---

## The rule

Explore several distinct framings and commit to the one with the strongest hook in the user's voice. If the framing is still genuinely ambiguous after that, offer 2-3 angles and ask which they want before proceeding.

A finished framing:
- Has a hook that makes a reader stop and engage — not the first, most obvious angle unless that angle genuinely is the strongest.
- Reads as the user telling a friend, not a recap of what was said.
- Stays inside the source. Never a framing that needs facts the content doesn't contain (no extrapolating).
- Is first person and casual (no third-person, formal, or academic voice).

## Framing palette (optional)

Angles that often carry a story. Reach for one when it fits; ignore the list when a better angle is already obvious.

| Angle | Fits when |
|-------|-----------|
| **Experiment to Routine** | Something new becoming everyday practice |
| **Competition** | Rivals racing, merging, or crowding each other out |
| **Threshold Crossed** | A capability or limit that just changed |
| **Foundations Maturing** | The layer underneath getting stable enough to build on |
| **New Approach** | A different way of doing a familiar thing |
| **In Practice** | How people are actually using this now |
| **Moving Parts** | How the pieces of a system affect each other |
| **Money** | Costs, prices, and who pays |
| **Changing Words** | A term starting to mean something different |
| **Human Limits** | Where people struggle |
