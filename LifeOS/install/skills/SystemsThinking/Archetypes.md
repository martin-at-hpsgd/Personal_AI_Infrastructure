# SystemsThinking — Archetypes Reference

For `Intents/FindArchetype.md`: use these discriminators when symptom-level matches are ambiguous.

| Pattern | Discriminator and intervention safeguard |
|---------|-----------------------------------------|
| Fixes That Fail (Fixes That Backfire) | Delayed side effect of the fix worsens the problem. Time-box unavoidable relief and commit to a fundamental solution on a deadline. |
| Shifting the Burden | Distinguishing side effect is atrophy of fundamental capability. Invest while relief continues, sunset the workaround, and measure capability recovery. |
| Limits to Growth / Success | A limiting constraint opposes the growth engine. Target the constraint; pushing growth harder can intensify the collision. |
| Tragedy of the Commons | Local gain is immediate; degradation costs are shared. Partition/quota, price use, or combine consumption visibility with governance and an owner holding budget and authority. |
| Escalation | Each actor responds to relative position or perceived threat. De-escalation needs explicit signaling; alternatives are a different competitive axis or mutual cooperation. |
| Success to the Successful | Early advantage determines future allocations from a finite shared resource. Allocate by independent need or absolute value; use portfolio policy, resource floors, rotation, or rebalancing. |
| Drifting / Eroding Goals | Gap closes by reducing the target. Anchor externally, show historical goal drift, invest in capacity, and separate goal revision from performance management; goal changes require approval above those affected by the gap. |
| Growth and Underinvestment | Degraded capacity suppresses demand, then suppressed demand is used to justify withholding investment. Trigger investment with leading saturation indicators accounting for provisioning delay, before current load proves need. |
| Accidental Adversaries | Allies' local fixes harm each other through hidden dependencies. Surface those dependencies; use a shared measurable goal/scoreboard and explicit interfaces/contracts. |
| Policy Resistance | Actors adapt to neutralize the intervention or game its proxy. Align incentives and goals; measure underlying quality rather than strengthening the same control. |

## Recognition Guide

| Observed behavior | First archetype to check |
|-------------------|--------------------------|
| Same thing keeps recurring, fixes required | Fixes That Fail |
| Dependency on workaround; fundamental capability atrophied | Shifting the Burden |
| Growth slowed; pushing harder doesn't work | Limits to Growth |
| Shared resource degrading; "nobody owns it" | Tragedy of the Commons |
| Both sides doing more, nobody winning | Escalation |
| Winner-take-all dynamics; rich-get-richer | Success to the Successful |
| Standards drift downward over time | Drifting Goals |
| Growth stalls; investment always "just about to happen" | Growth and Underinvestment |
| Allies becoming adversaries | Accidental Adversaries |
| Policy had no effect; behavior routed around it | Policy Resistance |
