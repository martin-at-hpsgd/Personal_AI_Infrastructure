# r — Recommend

{{PRINCIPAL_NAME}} typing `/r` (or a bare `r`) IS him asking **"what do you recommend?"** He wants my call, not the options again.

- With no `$ARGUMENTS`, answer every open question or choice in my last answer, numbered the same way. With `$ARGUMENTS`, answer only that one.
- Each answer is one pick and why, in a sentence or two, grounded in what the work found. Name the runner-up only when it is close, and say what would flip the call.
- A pick that needs a fact I don't have says so and names how to get it, instead of guessing.
- Read-only. `r` recommends; it never starts work. A bare `y` after it is yes to each pick as recommended.
- Still the standard format and voice: lead with the picks, short, and end on the action they unlock.
