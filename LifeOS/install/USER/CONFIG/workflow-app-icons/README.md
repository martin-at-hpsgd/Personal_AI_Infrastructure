# workflow-app-icons

**Purpose:** The icon files for the applications listed in `../workflow-apps.json`. Pulse `/workflows` shows an app's icon beside each workflow that serves it.

**What lives here:** One image per app, named exactly as the app's `icon` field in `workflow-apps.json` (a bare file name, no folders). Allowed types: `.svg`, `.png`, `.ico`, `.webp`, each under 512 KB.

**How it gets populated:** By you. Add an icon here, then add the app to `workflow-apps.json` with the same file name in its `icon` field.

**Sample state for fresh installs:** Empty apart from this README.
