# DefineGoal

A pre-registered goal specification that makes success independently checkable before any investigation starts.

## Ideal State

- The goal is an independently checkable end state with a deadline, observable failure conditions, minimum/target/stretch thresholds, and explicit boundaries.
- The record is a **Goal Specification: project/problem name** with every section the Output format table requires, including the Pre-Registration timestamp at which criteria were locked, before evidence collection.

## Anti-criteria

- Investigation never begins until success is specific, measurable, falsifiable, timebound, and constrained.
- Criteria are never rewritten after data collection begins; a goal that proves wrong is acknowledged as a reframing that preserves the original verdict.

## Output format

Produce **Goal Specification: project/problem name**, with Date and Owner.

| Section | Required content |
|---------|------------------|
| Outcome | End state described as achieved |
| Success Criteria | Measurable criterion checkboxes; quantitative targets and qualitative behaviors; distinguish leading signals from lagging confirmation |
| Thresholds | Minimum acceptable, target, stretch |
| Constraints | Time, resources, quality, technical, ethical |
| Anti-Goals | Explicit exclusions |
| Pre-Registration | Timestamp at which criteria were locked, before evidence collection |
